How to play

Objective

Validate the circuit by turning on the exit component.

Input

Switch the input between on and off.

Building circuit path

Drag logic gates from the side panel onto the open grid spaces.

Connect the gates

Use wires on the gate's left and right pins.

Validate

When all exits are on, validate your circuit to complete the level.

Gate cheat sheet

  • AND: both inputs are ON
  • OR: either input is ON
  • XOR: exactly one input is ON
  • NOT: reverses its input
